# LLM 学习与实践

这个仓库统一保存学习过程中的代码、学习文档和讲解文档。目前是内容目录，待补充具体材料；目录中的说明文件不是已完成的课程内容。

| 目录 | 内容 |
| --- | --- |
| [`code/`](code/) | 可运行的示例、练习和项目代码 |
| [`learning-docs/`](learning-docs/) | 学习笔记、知识点与参考资料 |
| [`explanations/`](explanations/) | 对应代码的思路、运行方式和逐步讲解 |

建议同一个主题在三个目录中使用相同的子目录名，方便互相定位。例如 `code/01-topic/`、`learning-docs/01-topic/` 和 `explanations/01-topic/`。

后续加入材料时，先保留原始代码与文档的来源和适用范围；如果示例需要密钥或账号，只提交配置示例，不提交真实凭据。
