**（1）Attention 和 Transformer 是什么关系？**

Attention 让每个 token 根据相关性，从其他位置提取信息：Q 和 K 算出分数，经过 softmax 得到权重，再对 V 加权求和。Transformer 用 Attention 处理 token 之间的联系，还包含前馈网络、残差连接和归一化等部分。

**（2）MHA、GQA 有什么区别？**

MHA 是多头注意力，每个头都有各自的 Q、K、V，可以从不同角度提取信息，但推理时需要缓存多组 K/V。GQA 保留多个 Q 头，让一组 Q 头共享同一组 K/V。例如 8 个 Q 头配 2 个 KV 头，每 4 个 Q 头共享一组 K/V，相同序列长度和头维度下，KV 缓存大小就降为原来的四分之一。只有 1 个 KV 头时就是 MQA。

**（3）MLA 又是怎么减少缓存的？**

MLA 是多头潜在注意力，通过低秩投影，把 K/V 的信息压缩到较小的潜在向量中，推理时缓存这个压缩表示，并保留位置编码所需的部分。GQA 减少的是 KV 头数，MLA 改变的是缓存的表示方式，需要配套的投影和注意力计算。
