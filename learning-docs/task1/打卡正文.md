**（1）为什么 Prefill 会受访存和中间矩阵影响，FlashAttention 改变了什么？**

Prefill 对整个 prompt 做 Attention。序列长度为 S 时，朴素实现会生成 S×S 的分数矩阵，做 softmax 后再乘 V。序列一长，中间矩阵就很占显存，反复读写也容易拖慢计算。FlashAttention 把 Q/K/V 分块，在片上边算边累加，省掉完整中间矩阵写回显存的过程。Attention 的计算量仍是二次增长，但需要搬运的数据少了。

**（2）tiling、online softmax、HBM 和 SRAM 分别起什么作用？**

Tiling 就是把大矩阵拆成小块，每次从 HBM（高带宽显存）搬一部分数据到 SRAM（片上快速存储）中计算。问题是：softmax 需要整行的分数，只看到一块怎么办？Online softmax 会记住当前行的最大值、指数和与输出累积量。遇到新块时更新这些值；如果最大值变了，就先把旧结果按比例缩放，再加入新块。这样不必保存整行分数，也能得到与完整 softmax 一致的结果，各块之间的归一化也能衔接起来。

**（3）GPU 架构与内存架构**

GPU 由多个 SM 组织线程并行执行，CUDA Core 做通用计算，Tensor Core 擅长矩阵乘加。内存从靠近计算单元的寄存器、共享内存/L1，到 L2，再到全局显存，容量和访问代价各不相同。对 FlashAttention 来说，片上空间小，需要分块使用；显存能放下更多数据，但来回搬运有成本。把当前块留在片上反复利用，算完再汇总输出，就能减少计算单元等数据的时间。
